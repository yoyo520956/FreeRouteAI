## 二、设计主题：AI 智能路由核心

构图元素（自外向内）：

1. **背景**：深蓝黑对角渐变 `#0C1222 → #04060C`，左上偏蓝、右下压暗，制造深度。
2. **轨道环**：两道同心细环（透明度 34 / 22），暗示"多路服务汇聚"的通道。
3. **8 个数据节点**：非均匀半径（0.82–1.06 倍）分布，避免机械感；每点为白色实心 + 青色光晕。
4. **数据线路**：从每个节点射向圆心，颜色由青色 `#78EBFF` 渐变到电光蓝 `#306CF5`，先高斯模糊成光晕层，再叠加清晰细线。
5. **中心核心**：径向渐变玻璃球（中心近白青 `#F0FCFF` → 边缘深蓝 `#145CE8`），左上一枚柔光高光，右上一段冷边光，外有两道接口环。
6. **收尾**：整体顶部玻璃高光 + 四角暗角，逼近 Apple 原生图标的立体质感。

约束执行情况：

- ✅ 无文字、无字母、无水印
- ✅ 深蓝黑背景
- ✅ 中心发光 AI 核心 + 多条蓝/青线路汇聚
- ✅ 无复杂背景与多余装饰
- ✅ 1024×1024，可直接进 Asset Catalog（`Contents.json` 已配好 universal / iOS / 1024x1024）

## 三、App 内视觉系统（`Components/FRDesign.swift`）

| Token | 值 | 用途 |
|---|---|---|
| `accent` | `#3B85FF` 电光蓝 | 主色、按钮、选中态 |
| `accentCyan` | `#33D9EB` 青色 | 辅色、数据强调 |
| `ok` | `#33C773` | 健康、成功 |
| `warn` | `#FF9E26` | 限流、警告 |
| `err` | `#FF5959` | 失败、熔断 |
| `deepBG` | `#0B101C` | 深色模式背景（深蓝黑） |
| `deepCard` | `#161C2D` | 深色卡片 |

- 浅色模式使用系统语义色（`systemGroupedBackground` / `secondarySystemGroupedBackground`），深色模式切到深蓝黑，两套都由 `FRBackground` / `FRCard` 自动处理。
- 图标一律 SF Symbols；材质用 `regularMaterial`；圆角统一 14pt。
- 空状态、错误状态用代码绘制的 `FREmptyState` 与 `FRRoutingGlyph`（与 App 图标同主题的路由核心图形），不依赖图片资源。
