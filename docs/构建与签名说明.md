## 二、关于「iOS 27.3 beta 1 SDK」的结论（重要）

需求指定用 iOS 27.3 beta 1 SDK 编译。**GitHub 公开 Runner 没有这个 SDK**：

- 主线 `macos-26` 最高 iOS 26.5 模拟器 SDK；
- 官方 Xcode 27 预览镜像最高 **iOS 27.2**；
- 因此不存在"用 iOS 27.3 beta SDK 构建"这条公开路径。

处理方式（不糊弄）：

1. 工作流第一步就把 `xcodebuild -version`、`swift --version`、`xcodebuild -showsdks` 的真实输出写进构建摘要；
2. **不偷偷改用低版本 SDK 冒充 27.3 构建成功**，也不伪造 beta SDK 记录；
3. 默认用 Runner 提供的最新正式版 Xcode（26.6）构建，最低部署目标保持 iOS 17.0，真机运行目标仍是 iOS 27.3 beta 1；
4. 所有 iOS 17 之后的新 API 都包在 `if #available` / `@available` 里，iOS 17 有回退路径；
5. 若你确实要用 iOS 27.3 beta SDK：在 Secrets 里提供 Apple ID，用 [`xcodes`](https://github.com/XcodesOrg/xcodes) 在作业里安装官方 beta，再把 `xcode` 入参改成对应版本 —— 这一步需要你授权并提供账号，我不会代你登录。

另外：**Xcode 27 预览镜像在 `actions/runner-images` 里以 `xcode-27-arm64` 目录发布，但官方 Readme 未写明可直接使用的 `runs-on` 标签**；工作流默认不依赖它，避免把作业调度到不存在的标签上假称"构建成功"。

## 三、模拟器机型（会影响截图）

Runner 的 Xcode 26 / 27 **都不再提供 iPhone SE (3rd generation) 模拟器**，可用机型为 iPhone 17 / 17 Pro / 17 Pro Max / 17e / 16e / Air。

- 工作流按 `iPhone SE 3 → iPhone SE 2 → iPhone 16e → iPhone 17e → iPhone Air → iPhone 17` 顺序自动挑选，并在摘要里明确警告"当前机型不是 SE 3"；
- 因此 **CI 截图不等于 SE 3（750×1334）真机截图**；SE 3 小屏适配必须在你的真机上验证。

## 四、签名

工作流提供三档，默认 `none`：

| 模式 | 需要的 Secrets | 结果 |
|---|---|---|
| `none` | 无 | Release 真机架构 Archive + **未签名 IPA**（`Payload/*.app` 结构完整，可验证打包链路，**不能直接安装**） |
| `manual` | `DEV_CERT_P12_BASE64`、`DEV_CERT_PASSWORD`、`MOBILE_PROVISION_BASE64`、`MOBILE_PROVISION_NAME`、`APPLE_TEAM_ID` | 云端导入钥匙串 + 描述文件，正式 Development 签名 IPA |
| `automatic` | `APPLE_ID`、`APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID` | `-allowProvisioningUpdates` 自动签名 |

所有证书、密码、Key 一律走 GitHub Actions Secrets，仓库里不出现任何凭据。

### 免费 Apple ID 的真实限制（不承诺做不到的事）

如果你用免费 Apple ID 侧载（AltStore / SideStore / Sideloadly 等），据 Apple 公开政策：

- 描述文件 **7 天有效**，到期需重新签名续期；
- 每年可创建的 App ID 数量有限，同时可安装的自签应用数量有限；
- **App Groups、Push、Live Activity 等能力通常要求付费 Apple Developer 账号**；本工程使用了 App Group（`group.com.freeroute.ai`，主 App 与 Live Activity 扩展共享监控数据）与 `aps-environment`，用免费账号签名时这两项很可能不可用；
- 结论：**不做"永久安装"或"免费账号全功能"的保证**。要完整功能（Live Activity、后台音频 PiP 保活、App Group）请用付费账号签名。

以上属于对外部政策的说明，具体以 Apple 当期条款与你的实测为准。

## 五、云端构建费用（已查官方文档）

- 本仓库是**公开仓库**：GitHub 官方文档明确 "Public repositories: This usage remains free"，即公开仓库使用 GitHub-hosted Runner（含 macOS）不消耗付费额度；
- 若将来转为**私有仓库**：macOS Runner 计费率高得多（官方价目 `actions_macos` = **$0.062/分钟**，约为 Linux 2 核的 10 倍），Free 计划每月仅 2,000 分钟含额度，实际可用 macOS 时长会被倍率大幅压缩 —— 届时请重新核算，不要假设 macOS 构建永久免费。

## 六、本地（无 Xcode 环境）能做的验证

开发容器是 iPhone 上的 Linux，没有 Xcode，因此提交前用静态自检兜底：

```bash
python3 tools/selfcheck.py     # 括号配平 / import 完整性 / 类型重复定义 / 占位实现扫描
python3 tools/make_icon.py     # 重新生成 AppIcon-1024.png
```

真正的编译错误只能由云端 Xcode 判定 —— 这也是本项目把 CI 当作唯一编译门的原因。
