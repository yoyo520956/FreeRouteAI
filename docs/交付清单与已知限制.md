### 4. SDK 状态：**iOS 27.3 beta SDK 在公开 Runner 上不存在**

- 主线 `macos-26` 最高 iOS 26.5 模拟器 SDK；官方 Xcode 27 预览镜像最高 **iOS 27.2**；
- 因此本项目**不谎称用 27.3 beta SDK 构建**。默认用 Runner 最新正式版（Xcode 26.6）编译，最低部署目标 iOS 17.0，新 API 全部 `#available` 包裹；
- 要用 27.3 beta 必须由你提供 Apple ID 让作业里 `xcodes` 安装，这需要你授权，我不会代你登录。

### 5. IPA 状态：**默认未签名，不能直接安装**

CI 默认产出未签名 IPA（验证打包链路用）。真正可安装的 IPA 需要你在 Secrets 里提供证书/描述文件或 Apple ID + Team ID。

**关于免费 Apple ID，不承诺的事**：描述文件 7 天到期、可安装数量受限；本工程用了 App Group（主 App 与 Live Activity 扩展共享数据）与推送环境键，免费账号很可能无法启用这两项能力。要完整功能需付费 Apple Developer 账号。

### 6. 已知的产品边界（不是 bug，是设计约束）

- **PiP 系统限制**：iOS 的 PiP 只在 App 退到后台/其他 App 之上时可见，且需要设备支持 `PictureInPictureMode.system`；不支持时自动降级为应用内悬浮窗 + Live Activity，界面会显示当前用的是哪条路径；
- **局域网网关在 iOS 上受本地网络权限约束**：首次监听会弹系统授权；App 挂起后监听即失效，这不是 bug 而是 iOS 生命周期规则；`UIBackgroundModes` 里的 `audio` 用于在流式输出期间争取更长的前台时间，不保证常驻；
- **免费额度信息会过期**：目录里每家都带"最后验证日期"，注册前必须打开官网核对；本 App 不绕过任何配额/账户/地区限制；
- **不支持模型目录的服务商**：把"模型列表路径"清空即显式声明不支持动态发现，界面如实提示手动添加模型，绝不生成假模型列表；
- **无法无损转换的字段**：适配器通过 `lossyNotes` 显式报告，不静默丢参数。
